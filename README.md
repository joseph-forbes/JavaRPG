# Java RPG #

This is a text adventure being developed alongside a CS-221 class. 


## Features

- Command parsing and world interaction
- World map system with entity hierarchy
- Item system
- Event handlers and world events
- Web page front end option

## Technologies

- Java
- JavaScript
- Spring REST
- Git/GitHub

## How to Run

To run Java backend, compile and run Adventure.java in javarpg/gameengine.
To run Web page front end, compile and run JavaRPGApplication.java, then go to http://localhost:8080 to input/receive commands.

## Current Development

This project is actively being developed. Current work includes:

- Quest mechanics to allow for a simple story
